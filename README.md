# 从磁扩散方程到交流电阻

> 集肤效应、涡流损耗与一维邻近效应近似的交互式可视化  
> 《电磁场》AI Co-Pilot 可视化微作品 / Course project: skin-effect-lab

在线访问地址：  
https://chenby-thu.github.io/skin-effect-lab/

## 作品简介

本作品围绕《电磁场》课程中“准静态时变场、磁扩散、集肤效应、涡流损耗和交流电阻”展开。用户可以通过滑块改变频率、导电率、相对磁导率和导体厚度，观察趋肤深度 `δ`、集肤强度 `a/δ`、电流密度 `J_z(x)`、焦耳热源 `q'''` 与损耗/等效电阻之间的联动。

页面不使用后端或服务器 API，所有计算均在浏览器本地完成。它的主线不是单纯画图，而是把

```text
磁扩散方程
→ H_y(x) 与 J_z(x) 的截面分布
→ q''' = |J|² / σ
→ P' 损耗积分
→ R_ac 或等效损耗指标
```

串成一条可交互的教学链条。

## 知识映射

- 法拉第电磁感应定律：变化磁场产生有旋感应电场。
- 磁准静态近似：忽略位移电流，保留传导电流和磁扩散过程。
- 磁扩散方程：在均匀导体中，`H`、`E`、`J` 满足扩散型控制方程。
- 趋肤深度 `δ`：表征时变场进入导体的特征深度。
- 集肤效应：高频下电流密度向表面集中，导致交流电阻增大。
- 涡流损耗：感应电流导致 `q''' = |J|²/σ` 的体热源。
- 邻近效应近似：外部磁场扰动改变导体内 `J_z(x)` 的分布，使局部热源增强。

## 设计逻辑

本作品选择一维平板模型，而不是直接做复杂 FEM，原因是：

- 一维模型能直接展示磁扩散方程如何改变截面内 `J_z(x)`。
- 滑块交互能把公式参数变化和物理图像变化连接起来。
- 三种模式分别对应“端子电流集肤”“外磁场涡流”“注入电流叠加外场扰动”。
- 页面强调从场方程到损耗积分的链条，而不是只展示视觉效果。

## 物理模型与坐标约定

研究对象是有限厚导体平板：

- 厚度方向：`x ∈ [-a, a]`
- 总厚度：`2a`
- 导体宽度：`b`
- 电流方向：`z`，电流密度为 `J_z(x)`
- 磁场方向：`y`，磁场为 `H_y(x)`
- 边界磁场：`H_y(-a)=H_L`，`H_y(a)=H_R`
- 正弦稳态相量使用 RMS 值

模型采用磁准静态近似，忽略位移电流；材料假设为线性、均匀、各向同性，`μ` 和 `σ` 为常数。

## 三种模式说明

### Mode A：注入电流：集肤效应与交流电阻

边界条件：

```text
H_y(-a) = -I/(2b)
H_y(a)  =  I/(2b)
```

端子电流给定，电流密度因磁扩散在截面内重新分布。该模式适合观察 `R_ac/R_dc` 随 `a/δ` 增大的变化，也是唯一严格定义端子交流电阻的模式。

### Mode B：外加时变磁场：涡流损耗

边界条件：

```text
H_y(-a) = H_0
H_y(a)  = H_0
```

边界施加切向时变磁场，导体内产生闭合感应电流。该模式适合展示涡流损耗 `P'_eddy` 和焦耳热源分布 `q'''(x)`；由于无端子净传输电流，不定义端子交流电阻 `R_ac`。

### Mode C：注入电流 + 外场扰动：一维邻近效应近似

边界条件：

```text
H_y(-a) = H_0 - I/(2b)
H_y(a)  = H_0 + I/(2b)
```

在注入电流基础上叠加外部时变磁场边界扰动，用于展示电流分布偏移、局部热源增强和等效损耗变化。它是邻近效应的教学化一维近似，不替代完整二维/三维多导体邻近效应 FEM 仿真。

## 公式链条

从 Maxwell 方程组子集出发：

```text
∇×H = J
∇×E = -∂B/∂t
J = σE
B = μH
```

可得一维正弦稳态磁扩散方程：

```text
d²H_y/dx² - Γ²H_y = 0
Γ = √(jωμσ) = (1+j)/δ
δ = √(2/(ω μ σ))
```

由场量回到损耗与电路量：

```text
J_z = dH_y/dx
q''' = |J_rms|² / σ
P' = b ∫_{-a}^{a} q''' dx
R_ac = P' / I_rms²
R_dc = 1/(σ·2ab)
```

对 Mode B，`P'` 是单位长度意义下的涡流损耗指标，不能直接称为端子交流电阻。

## 典型参数场景

页面提供一键场景：

- 低频近似直流：观察 `a/δ < 0.1` 时 `J_z(x)` 近似均匀，Mode A 下 `R_ac/R_dc ≈ 1`。
- 高频强集肤：观察表面层电流集中和 `R_ac/R_dc` 上升。
- 高磁导率材料对比：观察 `μ` 增大导致 `δ` 减小、电流集中增强。
- 外加时变磁场：Mode B，无端子净传输电流，观察涡流损耗。
- 注入电流 + 外场扰动：Mode C，观察一维邻近效应近似下的左右不对称电流分布。

## 模型假设与适用边界

- 一维平板导体模型。
- 材料均匀、线性、各向同性。
- 正弦稳态。
- 磁准静态近似。
- 不包含完整二维/三维几何边界。
- 不包含温升反馈、非线性磁导率、端部效应、真实多导体耦合。
- 可用于理解物理机制，不应直接作为工程设计定量结果。

这些限制是模型适用范围的一部分，并不表示模型无效；它适合用来说明从磁扩散方程到一维电流重分布、涡流损耗和交流电阻的主干物理。

## GitHub Pages 部署方式

项目保留 Vite 的 Pages 路径配置：

```ts
base: "/skin-effect-lab/"
```

并提供 `.github/workflows/deploy.yml`。推送到 `main` 分支后，GitHub Actions 会执行：

```bash
npm ci
npm run build
```

随后上传 `dist` 并部署到 GitHub Pages。仓库 `Settings -> Pages` 中建议将 `Build and deployment` 的 `Source` 设为 `GitHub Actions`。
