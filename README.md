# skin-effect-lab

《从磁扩散方程到交流电阻：集肤效应、涡流与邻近效应的一维可视化》

在线访问地址：

https://chenby-thu.github.io/skin-effect-lab/

## 项目简介

本项目是一个《电磁场》课程 AI Co-Pilot 可视化微作品。它使用 Vite + React + TypeScript 构建一维有限厚导体板模型，把

```text
时变磁场 / 交流电流
→ 感应电场
→ 导体内部电流密度 J(x) 重新分布
→ 局部焦耳热 q'''
→ 单位长度交流损耗 P_ac'
→ 交流电阻 R_ac'
```

串成一条可交互的教学主线。页面不使用后端或服务器 API，所有计算均在浏览器本地完成。

## 物理模型与坐标约定

研究对象是有限厚导体板：

- 厚度方向：`x ∈ [-a, a]`
- 总厚度：`2a`
- 导体宽度：`b`
- 电流方向：`z`，电流密度为 `J_z(x)`
- 磁场方向：`y`，磁场为 `H_y(x)`
- 边界磁场：`H_y(-a)=H_L`，`H_y(a)=H_R`
- 正弦稳态相量使用 RMS 值

模型采用磁准静态近似，忽略位移电流；材料假设为线性、均匀、各向同性，`μ` 和 `σ` 为常数。

## 三种模式 A/B/C

- 模式 A：端子注入交流电流。边界条件为 `H_L=-I/(2b)`，`H_R=I/(2b)`，用于观察集肤效应和由损耗积分得到的交流电阻。
- 模式 B：外加交变磁场涡流。边界条件为 `H_L=H0`，`H_R=H0`，无端子净传输电流，但会出现闭合涡流和焦耳损耗。
- 模式 C：端子注入电流 + 外加磁场扰动。边界条件为 `H_L=H0-I/(2b)`，`H_R=H0+I/(2b)`，用于展示左右不对称的 `J_z(x)`。

模式 C 不是完整二维/三维邻近效应仿真，而是用外加一维交变磁场扰动模拟邻近导体造成的左右不对称电流分布。

## 公式链条

从 Maxwell 子集出发：

```text
∇×H = J
∇×E = -∂B/∂t
J = σE
B = μH
```

可得磁扩散方程：

```text
∇²H = μσ ∂H/∂t
```

一维正弦稳态下：

```text
d²H_y/dx² - Γ²H_y = 0
Γ = √(jωμσ) = (1+j)/δ
δ = √(2/(ωμσ))
```

由场量回到电路量：

```text
J_z = dH_y/dx
q''' = |J_rms|² / σ
P_ac' = b/σ ∫ |J_rms|² dx
R_ac' = P_ac' / I_rms²
R_dc' = 1/(σ·2ab)
```

统一边值问题的解析形式为：

```text
H_y(x) =
H_L sinh(Γ(a-x))/sinh(2Γa)
+ H_R sinh(Γ(x+a))/sinh(2Γa)
```

```text
J_z(x) =
[-Γ H_L cosh(Γ(a-x)) + Γ H_R cosh(Γ(x+a))]/sinh(2Γa)
```

页面强调 `a/δ` 这个核心无量纲量：

- `a/δ < 0.1`：低频/弱集肤，电流近似均匀
- `0.1 ≤ a/δ < 1`：轻微集肤
- `1 ≤ a/δ < 5`：中等集肤
- `a/δ ≥ 5`：强集肤，主要电流集中在表面约 `δ` 厚度内

## 典型实验场景

页面提供一键 Presets：

- 低频近似直流：铜、50 Hz、小半厚度，目标是 `a/δ < 0.1`，观察 `R_ac/R_dc ≈ 1`。
- 高频强集肤：铜、1 MHz，观察电流向表面集中和 `R_ac/R_dc` 明显上升。
- 高磁导率材料对比：简化钢模型，观察 `μ` 增大使 `δ` 减小、集肤效应增强。
- 外加磁场涡流：模式 B，无端子净传输电流，观察外磁场诱发损耗。
- 注入电流 + 外磁场扰动：模式 C，观察一维邻近效应近似下的左右不对称电流分布。

## 模型校验方法

页面底部“模型校验”区域使用 pass / warn / fail 状态显示：

- 模式 A 净电流：`I_net` 是否接近输入 `I_rms`
- 模式 B 净传输电流：`I_net` 是否接近 0
- 模式 B 涡流反对称：`J_z(x)+J_z(-x)` 的残差
- 低频极限：当 `a/δ < 0.1` 时，`R_ac/R_dc` 是否接近 1
- 损耗非负：`P_ac' >= 0`
- 边界条件残差：数值端点 `H_y(-a)`、`H_y(a)` 是否接近 `H_L`、`H_R`
- 强集肤趋势：当 `a/δ > 5` 时，提示 `R_ac/R_dc` 应明显大于 1 并随 `a/δ` 增大而上升
- 模式 A 对称性：无外磁场时 `|J_z(x)|` 关于中心面对称

## 已知限制

- 本模型是一维平板近似，只解析厚度方向分布。
- 忽略边缘效应和端部效应。
- 忽略位移电流，采用磁准静态 MQS 近似。
- `μ` 和 `σ` 假设为常数。
- 未考虑真实多导体邻近效应的二维/三维耦合。
- 简化钢模型仅用于定性演示，真实铁磁材料的 `μ` 可能非线性、频率相关，并受温度、磁滞和饱和影响。

这些限制是模型适用范围的一部分，并不表示模型无效；它适合用来说明从磁扩散方程到一维电流重分布、涡流损耗和交流电阻的主干物理。
