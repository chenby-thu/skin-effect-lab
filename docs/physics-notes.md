# 物理说明

## 1. 从磁准静态方程到扩散方程

在良导体的低频到射频问题中，如果系统尺度远小于电磁波波长，可采用磁准静态近似并忽略位移电流。基本方程为：

```text
∇×H = J
∇×E = -∂B/∂t
J = σE
B = μH
```

对安培环路定律取旋度：

```text
∇×(∇×H) = ∇×J
```

利用向量恒等式：

```text
∇×(∇×H) = ∇(∇·H) - ∇²H
```

线性均匀介质中 `∇·B=0`，且 `B=μH`，所以 `∇·H=0`。因此：

```text
-∇²H = ∇×J
```

又因为 `J=σE` 且 `σ` 为常数：

```text
∇×J = σ∇×E = -σ∂B/∂t = -μσ∂H/∂t
```

代入得到磁扩散方程：

```text
∇²H = μσ ∂H/∂t
```

对于一维平板，磁场只有 `Hy(x)` 分量：

```text
∂²Hy/∂x² = μσ ∂Hy/∂t
```

## 2. 为什么 Γ = (1+j)/δ

设正弦稳态相量为：

```text
Hy(x,t) = Re{Hy(x) exp(jωt)}
```

则时间微分对应乘以 `jω`，扩散方程变为：

```text
d²Hy/dx² = jωμσ Hy
```

写成标准形式：

```text
d²Hy/dx² - Γ²Hy = 0
Γ² = jωμσ
```

因为：

```text
j = exp(jπ/2)
sqrt(j) = exp(jπ/4) = (1+j)/sqrt(2)
```

所以：

```text
Γ = sqrt(jωμσ)
  = (1+j)sqrt(ωμσ/2)
```

定义趋肤深度：

```text
δ = sqrt(2/(ωμσ))
```

于是：

```text
Γ = (1+j)/δ
```

这说明导体内部场量不仅有幅值衰减，也有相位滞后。将集肤效应简单写成 `exp(-x/δ)` 会丢失相位信息；完整相量形式包含 `exp(-(1+j)x/δ)`。

## 3. 三种边界条件

统一边界条件为：

```text
Hy(-a) = HL
Hy(a) = HR
```

通解为：

```text
Hy(x) =
HL sinh(Γ(a-x))/sinh(2Γa)
+ HR sinh(Γ(x+a))/sinh(2Γa)
```

电流密度由安培定律得到：

```text
Jz(x) = dHy/dx
```

即：

```text
Jz(x) =
[-Γ HL cosh(Γ(a-x)) + Γ HR cosh(Γ(x+a))]/sinh(2Γa)
```

模式 A 为端子注入交流电流：

```text
HL = -I/(2b)
HR =  I/(2b)
```

此时净电流满足：

```text
b ∫ Jz dx ≈ I
```

模式 B 为外加交变磁场涡流：

```text
HL = H0
HR = H0
```

两侧边界磁场相同，没有净传输电流：

```text
b ∫ Jz dx ≈ 0
```

模式 C 为注入电流与外加交变磁场叠加：

```text
HL = H0 - I/(2b)
HR = H0 + I/(2b)
```

外加磁场会破坏两侧表面电流的对称性，可视为一维邻近效应近似。

## 4. 由 J(x) 计算 q'''、Pac、Rac

本项目统一使用 RMS 相量。局部单位体积平均热源为：

```text
q'''(x) = |Jrms(x)|²/σ
```

单位长度平均损耗为：

```text
Pac' = b ∫ q'''(x) dx
     = b/σ ∫ |Jrms(x)|² dx
```

若存在端子注入电流 `Irms > 0`，单位长度交流电阻定义为：

```text
Rac' = Pac'/Irms²
```

直流均匀电流下：

```text
Jdc = I/(2ab)
```

对应单位长度直流电阻：

```text
Rdc' = 1/(σ·2ab)
```

因此 `Rac'/Rdc'` 可作为交流损耗相对直流损耗的放大倍数。

## 5. 强集肤近似的适用条件

趋肤深度 `δ` 是场量进入导体的特征深度。判断强弱时应看无量纲比值：

```text
a/δ
```

当 `a/δ < 0.1` 时，导体半厚度远小于趋肤深度，电流近似均匀，通常有：

```text
Rac ≈ Rdc
```

当 `a/δ > 5` 时，导体内部大部分区域电流很小，电流主要集中在两个表面附近，可以称为强集肤区。

中间区域不能直接套用强集肤近似，应使用完整的双曲函数解或数值模型。

## 6. 本模型的局限

- 一维平板近似
- 忽略边缘效应
- 忽略位移电流
- 假设 `μ`、`σ` 常数
- 铁磁材料真实 `μ` 可能非线性且频率相关
- 未考虑真实多导体邻近效应的二维或三维耦合

因此，本项目适合用于理解磁扩散方程、趋肤效应、涡流和交流电阻之间的联系，不应直接替代工程中的二维或三维电磁场仿真。
